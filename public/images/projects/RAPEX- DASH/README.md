# RAPEX DASH

Reserved media folder for the RAPEX DASH 3D arcade courier runner portfolio case study.

Add the original files here using these names:

- `gameplay-01.png`
- `gameplay-02.png`
- `gameplay-03.png`
- `start-screen.png`
- `rapex-dash-gameplay.mp4`
- `playable-build/` for a future static web export

The portfolio already contains an interactive mini-preview. The original screenshots, gameplay video, or exported browser build can be connected later without changing the case-study route.
