# Portfolio collection asset folders

Each project card has a stable folder below this directory. Add final images or videos to its project folder, then connect the file path in the matching gallery data.

The floating viewer supports any number of tabs. Tabs are intentionally allowed to vary by project: two, three, four, five, six, or more.

## Folder map

- `product-design/<project-name>/`
- `graphic/<project-name>/`
- `motion/<project-name>/`
- `audio/<project-name>/`
- `visual-art/<project-name>/`
- `web-interactive/<project-name>/`
- `mobile-apps/<project-name>/`
- `photography/<project-name>/`

Existing finished Web detail screens remain authoritative. Their assets should stay in their current folders; this map only reserves predictable locations for new media.
